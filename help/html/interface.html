Export buttons

  • Save to JPG — saves the current chart (enabled after a successful fetch).
  • Export CSV — writes the processed data table to a CSV file.
  • CSV + Infographic — exports the CSV and publishes an Infogram infographic.
  • Infogram Token — stores your Infogram API token and lets you pick the template project from a list of your projects.
See Exporting Data for details on all three.

Results area (bottom)

  • Left table — the averaged values: date label, max temp, min temp, and precipitation.
  • Right chart — temperature lines and precipitation bars.
  • Summary under the chart — the Conditions & Extremes and/or Yearly Breakdown text you enabled, in a scrollable panel.

Help menu and F1

The Help menu opens this help file's contents, specific topics, and the About box. Press F1 at any time — with the mouse over a control (or just after using it with the keyboard) F1 opens the help topic for that specific control.

Your settings are remembered

Location, period, depth, units, toggles, threshold, and Infogram token/template are saved to ui_settings.json after each successful fetch and reloaded at startup. In installed builds the file lives in your application-data folder (%APPDATA%\WeatherSnake on Windows).
