Units

The Units selector chooses the measurement system for the whole analysis — chart axes, the data table, and every summary, including differences in the Recent vs Baseline comparison.

QuantityMetricImperial
Temperature°C°F
Precipitationmminches

Conversions used

  • °F = °C × 9/5 + 32
  • inches = mm ÷ 25.4

Where each unit applies

  • Chart axes and legends.
  • The data table (right-click-free, values shown to one decimal).
  • Conditions & Extremes: typical ranges, records, wettest/driest years, rain-day threshold.
  • Yearly Breakdown and Recent vs Baseline, including the Change column.
  • CSV export — values are exported in the units selected at the time.
Min Precip (mm) is always entered in millimetres regardless of the units setting — see Precipitation Threshold.

Command line equivalent

python weather_juice.py --city Johannesburg --period Winter --depth 10 --units imperial
