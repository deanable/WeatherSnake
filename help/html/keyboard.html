Keyboard Shortcuts

KeysAction
F1Context-sensitive help for the focused control; general help when no specific control is focused.
Ctrl+F1Open the Help Topics window (contents, index, search).
Ctrl+SSave the current chart as a JPG.
Ctrl+EExport the processed data to CSV.
Ctrl+RFetch data (same as the Fetch Data button).
EscIn the custom-location entry: return to the preset list.

How context-sensitive F1 works

Every input control in WeatherSnake is registered with a help topic. Press F1 while the mouse hovers over a control (or immediately after tabbing to it) and the help window opens directly at that control's topic — the Location box opens Choosing a Location, the depth picker opens Analysis Depth, and so on. The full mapping is listed on the window overview page.

Tooltips show a one-line hint on hover; F1 opens the full topic. Use tooltips for a reminder and F1 for the explanation.
