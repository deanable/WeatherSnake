Choosing a Location

Preset locations

The Location dropdown offers three built-in presets:

  • Cape Town
  • Johannesburg
  • Durban

On the command line, list them with python weather_juice.py --list-presets.

Custom locations

Choose Custom… and type any town, city, or region name. WeatherSnake sends the name to the Open-Meteo Geocoding API and uses the best match. If the name is ambiguous, the geocoder's top result wins — include the country or region for precision (for example Richmond, Virginia or Richmond UK).

Press Escape in the custom box to switch back to the preset list.

Not found? Check the spelling or try a nearby larger city — the archive data is gridded, so a larger neighbour gives nearly identical results. See Troubleshooting.

Command line equivalent

python weather_juice.py --city "Cape Town" --period Winter --depth 10
