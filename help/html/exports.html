Exporting Data

Save to JPG

Saves the current chart as a JPEG image (300 dpi). The suggested filename encodes the depth, period, and location — for example 10yr_Summer_Durban.jpg — and you can change it in the save dialog. The button is enabled after a successful fetch. Use Ctrl+S as a shortcut.

Export CSV

Writes the processed data table — the same rows shown in the left-hand tree — to a CSV file named weather_report_<city>_<period>.csv. Values are in the units selected when the data was fetched. Columns:

  • date_label — month name or day-of-year label.
  • temp_max / temp_min — averaged highs and lows.
  • precip_sum — averaged precipitation.

CSV files open cleanly in Excel, LibreOffice, R, or Python (pandas.read_csv).

CSV + Online Chart (Datawrapper)

Performs the CSV export and then publishes an interactive Datawrapper chart from the same data — the requests run in the background, so the window stays responsive and the status bar shows progress:

  1. Create a free Datawrapper account (app.datawrapper.de) and generate an API token under Settings & Account → API tokens. One token is all you need — no template or project ID.
  2. Click Datawrapper Token, paste the token, and WeatherSnake verifies it against the API and stores it locally in ui_settings.json. Alternatively set the DATAWRAPPER_ACCESS_TOKEN environment variable.
  3. Press CSV + Online Chart. WeatherSnake creates the chart, uploads your weather data, labels the series (max/min temperature and precipitation), and publishes it — then shows the public link (it opens in your browser if you accept). The chart is interactive and responsive on the Datawrapper site and can be embedded from there.
  4. On failure a dialog explains exactly what went wrong — unreachable service, rejected token (with the server's response), or an exhausted free-tier quota (500 creates / 1,000 publishes per month) — and the details are also written to the log file. If a step fails after creation, the unfinished chart remains in your Datawrapper account so nothing is lost.

QuickChart PNG

Renders the current data as a PNG chart image via QuickChart (quickchart.io) — no account and no API key needed for the free tier (1,000 charts per month, 60 per minute). The image is saved next to the working directory as weather_quickchart_<city>_<period>.png and mirrors the in-app figure: temperature lines on the left axis, precipitation bars on the right. QuickChart is open source and can also be self-hosted for unlimited use.

Command line exports
