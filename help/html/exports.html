Exporting Data

Save to JPG

Saves the current chart as a JPEG image (300 dpi). The suggested filename encodes the depth, period, and location — for example 10yr_Summer_Durban.jpg — and you can change it in the save dialog. The button is enabled after a successful fetch. Use Ctrl+S as a shortcut.

Export CSV

Writes the processed data table — the same rows shown in the left-hand tree — to a CSV file named weather_report_<city>_<period>.csv. Values are in the units selected when the data was fetched. Columns:

  • date_label — month name or day-of-year label.
  • temp_max / temp_min — averaged highs and lows.
  • precip_sum — averaged precipitation.

CSV files open cleanly in Excel, LibreOffice, R, or Python (pandas.read_csv).

CSV + Infographic

Performs the CSV export and then publishes an Infogram infographic from the same data — the requests run in the background, so the window stays responsive and the status bar shows progress:

  1. Create a template project in Infogram (infogr.am): a project containing a text block (for the title) and a table chart (for the data). Infogram's API cannot create projects, so this one step happens in their editor.
  2. Create an API token in your Infogram account settings (API section). One token is enough — no secret key is needed.
  3. Click Infogram Token, paste the token, and WeatherSnake fetches your project list — pick the template from the dialog (or choose Enter ID manually and paste the project ID from the project card's context menu). Credentials are stored locally in ui_settings.json. Alternatively set the INFOGRAM_API_TOKEN and INFOGRAM_TEMPLATE_ID environment variables.
  4. Press CSV + Infographic. WeatherSnake copies the template, fills the text block with the location/period title and the table chart with your weather data, then publishes it and shows the share link (it opens in your browser if you accept).
  5. On failure a dialog explains exactly what went wrong — unreachable service, rejected token (with the server's response), a template without a chart block, or an Infogram server-side problem — and the details are also written to the log file. If a step fails after copying, the half-filled draft remains in your Infogram library so nothing is lost.
Template required. The current Infogram API cannot build a project from scratch: it edits copies of an existing template. Projects publish as private (link-only) by default.

Every CLI run automatically writes both files next to the working directory:
