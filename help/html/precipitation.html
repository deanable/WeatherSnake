Precipitation Threshold

Min Precip (mm) sets a floor under which daily precipitation is treated as zero before averaging. It exists to exclude trace moisture — dew, frost, and drizzle remnants — that would otherwise keep a "dry" month from ever averaging to 0.

How to use it

  • 0 — no threshold; every drop counts (the default).
  • 1 — a common choice; matches the "rain day" definition used in the conditions summary (days with ≥ 1 mm).
  • 5 — aggressive; only meaningful rain counts. Good for irrigation-style "will it actually wet the soil" questions.

The threshold is applied to the daily values and re-applied after averaging, so a mean built from a mix of zeros and small values can still be floored at the threshold.

Units note: this value is always in millimetres, even when the rest of the analysis is displayed in imperial units.
Related setting: the rain-day share in Conditions & Extremes always uses the fixed 1 mm definition documented in Weather Conditions.

Command line equivalent

python weather_juice.py --city "Cape Town" --period Winter --depth 10 --precip-threshold 1.0
